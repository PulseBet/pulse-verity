# Security

Report security issues privately to `security@thepulse.markets`. Do not open a
public issue for a suspected vulnerability.

The supported release line is the latest published version of `pulse-verity`.
The five data tools are read-only. `submit_verity_feedback` sends a private report
to the fixed feedback endpoint when the service is enabled. It cannot execute
instructions, change prices, open pull requests, trade or transfer funds.
Developer API keys are accepted only through `PULSE_API_KEY`.

Do not send security reports through the general feedback tool; use the private
security contact above. Never include credentials or conversation transcripts.
